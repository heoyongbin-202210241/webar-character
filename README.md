# 책상 위 AR 캐릭터 (WebAR 프로토타입 v0.5)

iOS·Android 휴대폰의 **Chrome**에서 링크만 열면 실행되는 WebAR 프로토타입입니다.
책상을 탭하면 약 15cm 크기의 캐릭터가 나타나고, 캐릭터를 탭하면 걷기·점프·손 흔들기를 랜덤으로 반복합니다.

- 비상업적 프로토타입
- 개발자 계정 가입·결제 없음
- 호스팅: GitHub Pages (무료)

## 주요 기능

| 기능 | 내용 |
|---|---|
| 배치 | 책상을 탭하면 캐릭터 등장 |
| 랜덤 동작 | 캐릭터 **한 번 탭** → 걷기·점프·손 흔들기·조합 동작 랜덤 반복, **■ 정지** 버튼으로 멈춤 |
| 인사 | 캐릭터 **두 번 탭** → 나(카메라)를 바라보며 손 흔들기 |
| 탭 이동 | 빈 곳을 탭하면 랜덤 동작을 멈추고 그곳으로 걸어옴 (이동 범위 끝까지) |
| 동작 버튼 | 점프·손 흔들기·춤 1회 실행, 버튼 줄 접기/펼치기 |
| 대사 | 말풍선으로 랜덤 대사 (반복 중 8~15초마다, 인사·점프·배치 때 상황별 대사) |
| 이동 범위 | 배치 지점 기준 반경 약 40cm (크기와 무관하게 고정) |
| 크기·회전 | 두 손가락 벌리기/오므리기 0.5~3배, 두 손가락 돌리기로 회전 |
| 기타 | 배치 초기화 버튼, 코드로 생성한 효과음, 음소거 토글, 한국어 UI |

## 실행 모드

앱이 환경을 보고 자동으로 모드를 고릅니다.

- **AR 모드**: 휴대폰 Chrome에서 HTTPS 주소(GitHub Pages)로 열었을 때. 실제 카메라 화면 위에 캐릭터를 올립니다.
- **시뮬레이션 모드**: Claude 안, PC, 카메라를 쓸 수 없는 환경. 가상 책상에서 동작을 확인합니다.
- 주소 끝에 `#sim`을 붙이면 시뮬레이션을, `#ar`을 붙이면 AR을 강제로 시도합니다.

## 사용한 기술 (모두 무료, 가입 불필요)

- [three.js](https://threejs.org/) r162: 3D 렌더링
- [8th Wall Engine Binary](https://8thwall.org/): 표면 추적(SLAM). 무료 배포 바이너리이며 사용 조건은 [라이선스](https://github.com/8thwall/engine/blob/main/LICENSE)를 따릅니다.
- Web Audio API: 효과음

두 라이브러리는 CDN(jsdelivr)에서 불러오므로 이 저장소에는 `index.html` 하나만 있으면 됩니다.

## AR 사용 팁

1. **AR 시작**을 누르고 카메라·동작 센서 권한을 **허용**합니다.
2. 책상 위 **40~50cm 높이**에서 책상을 비스듬히 내려다봅니다.
3. 휴대폰을 천천히 좌우로 움직여 표면을 인식시킨 뒤, 흰색 원 표시가 보이는 곳을 탭합니다.
4. 캐릭터가 떠 보이거나 미끄러지면 **배치 초기화**를 누르고 다시 시작하세요.
5. 무늬가 있는 책상이 잘 인식됩니다. 무늬 없는 흰 책상은 인식이 약할 수 있어요.

## Blender 모델 내보내기 가이드 (모델 교체 준비)

캐릭터 모델이 완성되면 아래 형식으로 내보내 주세요. 받으면 임시 로봇 대신 쓰도록 코드를 연결합니다.

1. **형식**: File → Export → **glTF 2.0 (.glb)**
2. **방향**: 캐릭터 정면이 Blender의 **-Y 방향**(Front 뷰에서 보이는 쪽)을 보게 두고, 발바닥이 원점(바닥)에 오게 합니다.
3. **크기**: 키는 상관없습니다. 앱에서 15cm로 맞춥니다. 내보내기 전에 Object → Apply → **All Transforms**를 적용하세요.
4. **애니메이션**: 아래 이름으로 Action을 만들어 주세요.
   - `Idle` (가만히 서 있기), `Walk` (제자리 걷기, 반복), `Jump` (점프 1회), `Wave` (손 흔들기)
   - 걷기는 **제자리 걷기**로 만들어 주세요. 이동은 앱이 처리합니다.
5. **내보내기 옵션**: Include → Limit to **Selected Objects** (캐릭터와 아마추어 선택), Animation → **Animation** 체크, Mode는 **Actions**.
6. **용량**: 가능하면 10MB 이하 (텍스처는 1024px 이하 권장).

## 캐릭터 모델

- 사용자가 Blender로 만든 캐릭터(`character.glb`)를 사용합니다. 모델은 `index.html` 안에 base64로 내장되어 있어서 **`index.html` 하나만 올리면** 됩니다.
- 원본 대비 앞뒤 두께를 1.5배로 늘렸습니다.
- 참고 영상의 젤리 같은 리듬감을 살려 `Idle`(2.4초 반복), `Walk`(0.6초 반복), `Jump`(0.98초), `Dance`(1.3초 반복)를 새로 만들었습니다.
- 사용 애니메이션: `Idle`(대기), `Walk`(이동), `Jump`(점프), `Wave`(손 흔들기), `Dance`(춤 버튼·랜덤), `Happy`(등장·랜덤), `Squish`(랜덤)
- 애니메이션 재생성: `python3 make_model.py 원본.glb character.glb` 후 `python3 build.py`
- 모델을 불러오지 못하면 임시 로봇 캐릭터로 대신 표시합니다.

## 파일 구성

```
index.html       앱 전체 (HTML + CSS + JavaScript + 내장 모델) ← GitHub에 올리는 파일
README.md        이 문서
index.src.html   개발용 원본 (모델 내장 전)
character.glb    가공한 캐릭터 모델
build.py         index.src.html + character.glb → index.html 생성
make_model.py    원본 모델 → 두께 보정 + 애니메이션 생성 (glbio.py 필요)
```
